Using the MCP Proxy & IRI API Server

The Jefferson Lab LQCD MCP Proxy and IRI Facility API integrate Slurm high-performance compute with AI assistants (Model Context Protocol) and multi-site DOE computational infrastructure.

⚖️ Choose Your Workflow

Depending on whether your workflow is focused on JLab alone or spans multiple national laboratory facilities, select the corresponding approach:

Workflow Mode Target Facilities Recommended Interface Primary Highlights
Option 1 JLab LQCD Only Web Dashboard Browser UI, 1-click login (CILogon/Globus/GitHub), Slurm MCP launcher, live log viewer, interactive tool runner.
Option 2 Multi-Site (JLab, NERSC, ALCF) get_globus_token.sh CLI Globus Auth token generator with unified IRI API scopes & Globus Transfer permissions across DOE sites.

🖥️ Option 1: Using the Web Dashboard JLab Resources Only

If you are only interacting with Jefferson Lab compute resources and Slurm queues, use the interactive Web Dashboard. No command-line token management is needed.

1
Access the Dashboard URL

Open your browser and navigate to the dashboard endpoint:

URL 
http://<mcp-proxy-host>:8000/jlab/lqcd/mcp/dashboard/
2
Sign In via Identity Provider

Click Sign In and authenticate via CILogon, Globus, GitHub, or Google. The server automatically associates your identity with your local JLab username and Slurm account allocations.

3
Utilize Dashboard Capabilities
📊 Cluster Status
Inspect idle/busy nodes, partition limits (CPU/GPU), memory allocations, and your project accounts.
🚀 Launch MCP Servers
Submit interactive MCP server batch jobs to Slurm nodes with custom scripts or server file paths.
🧪 In-Browser Tool Runner
Introspect active tools on running MCP servers, provide parameters, and execute tools directly on the web page.
📜 Real-time Log Viewer
Read stdout and stderr streams for active Slurm jobs without requiring an SSH connection.
📦 Config Exporter
Generate one-click JSON configurations for VS Code (mcp.json) or Claude Desktop.

🌐 Option 2: Using get_globus_token.sh Multi-Site (JLab, NERSC, ALCF)

When orchestrating workflows across multiple facilities (such as querying both JLab and NERSC, or moving data between JLab DTN and ALCF), use get_globus_token.sh to generate unified Globus Auth and Transfer tokens.

1
Run the Token Helper Script

Run the shell wrapper script. It automatically ensures globus-sdk is available:

Bash 
./get_globus_token.sh
2
Complete Interactive Authorization

Open the printed Globus authorization link in your browser, log in, grant consent for requested facility scopes (JLab, NERSC, ALCF, Transfer), and paste the resulting auth code back into your terminal.

🔒 Secure Storage
Tokens are stored securely at ~/.globus/auth_tokens.json with private permissions (0600).
3
Useful Script Commands
Command Examples 
# 1. Request tokens for specific facilities
./get_globus_token.sh --facilities jlab nersc

# 2. Output access tokens to stdout for scripts or environment variables
./get_globus_token.sh --print-token

# 3. Refresh saved tokens silently in the background
./get_globus_token.sh --refresh-only

# 4. Force a fresh browser login
./get_globus_token.sh --force-login --prompt-login

# 5. Validate tokens against live facility endpoints
./get_globus_token.sh --validate-iri
4
Calling Services with Acquired Tokens

Use the generated tokens in HTTP headers when querying MCP Proxy or facility IRI API endpoints:

API Requests 
# Query JLab MCP Proxy
curl -X POST http://<mcp-proxy-host>:8000/cloud/my-server/mcp \
  -H "Authorization: Bearer <JLAB_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc": "2.0", "method": "tools/list", "id": 1}'

# Query NERSC IRI API Status
curl -X GET https://api.iri.nersc.gov/api/v2/account/projects \
  -H "Authorization: Bearer <NERSC_TOKEN>"

# Submit JLab compute job with facility project header
curl -X POST http://<jlab-iri-host>:8000/api/v2/compute/jobs \
  -H "Authorization: Bearer <JLAB_TOKEN>" \
  -H "X-IRI-Facility-Project: lqcd" \
  -H "Content-Type: application/json" \
  -d @job_spec.json

🔌 Connecting VS Code & Claude Desktop

To connect your IDE or local AI assistant to a running MCP server managed by the proxy:

VS Code (.vscode/mcp.json) 
{
  "mcpServers": {
    "jlab-lqcd-mcp": {
      "url": "http://<mcp-proxy-host>:8000/cloud/<server_name>/mcp",
      "type": "http"
    }
  }
}

  }
}

🛠️ Troubleshooting & FAQs

⚠️ 401 Unauthorized Error
Your token may have expired. Re-run ./get_globus_token.sh --force-login, or click Sign In in the Web Dashboard.
🏢 ALCF Identity Requirements
ALCF IRI API requires an ALCF identity as the primary Globus identity. When querying ALCF, ensure you authenticate with your ALCF account.
⏳ MCP Server State is PENDING
Slurm has queued your server job. Tools will automatically become active in the dashboard once the job transitions to RUNNING.
📁 Job Logs Not Showing
Slurm flushes stdout in chunks. If logs are empty immediately after launch, wait a few seconds and click Refresh.
